# 차분 · 밤공기 방향 전체 화면 시안

만든 날: 2026-11-15 (KST). `01_주차후화면_세방향`에서 고른 B안(밤공기)을 모든 화면으로 넓힌 것입니다.

## 보는 방법

`index.html`을 브라우저로 엽니다. 인터넷 연결은 필요 없습니다.

| 조작 | 하는 일 |
| --- | --- |
| 왼쪽 목록 | 화면과 상태 고르기 |
| `낮 화면` / `밤 화면` | 낮과 밤 바꾸기 (키보드 D, N) |
| `차량 화면 속에서 보기` | Pleos 화면 전체(2560 × 1440) 안에 앱 창을 넣어 보기 |
| `비워 둔 왼쪽 위 구역 표시` | 측방 카메라 화면 자리로 비워 둔 구역(480 × 200으로 가정) 표시 |
| 화면 속 버튼 | 실제로 눌립니다. 예: `오피스 모드` → 켜는 순서 → 작업 화면 → `원래대로` → 주차 후 화면 |

## 들어 있는 화면

| 묶음 | 상태 |
| --- | --- |
| 주차 후 화면 | 통화 메모(전체 내용 펼침, 못 들은 부분 없음 포함), 통화가 없을 때 |
| 오피스 모드 | 켜는 중(5단계), 작업, 회의, 배터리 부족, 설정 바꾸기, 원래대로 되돌리는 중, 멈춤, 잠김 |
| 주행 중 작은 창 | 대기, 실내 조절, 못 들은 구간, 통화 종료 후(Gleo가 "통화 요약을 듣고 싶으신가요?"라고 화면과 음성으로 물음), Gleo와 대화("네"라고 답함, 요약을 들려줌), 차량이 조작을 거부함, 자동 조절을 껐을 때 |
| 그 밖 | 첫 실행 동의, 상태 카드 |

`미리보기` 폴더에 모든 상태의 낮·밤 그림(1682 × 1210)이 있습니다. `한눈에_보기.png`는 주요 화면을 한 장에 모은 것입니다.

| 오피스 모드 켜기와 끄기 | 차량 그림 위에서 움직이는 부위가 빛나며 차례로 진행 |

| 주행 중 작은 창 | 바람 줄기가 한 번 짧아짐, Gleo 목소리 물결. Gleo와 대화할 때는 Gleo의 말(왼쪽)과 운전자의 말(오른쪽 말풍선)이 대화처럼 차례로 쌓임. 지금 말은 크게, 지난 말은 두 개까지만 작고 흐리게 남음. Gleo가 말할 때는 말하는 속도에 맞춰 낱말이 밝아지고, 운전자 차례에는 "듣고 있습니다"가 알아들은 말로 바뀜. 그 밖에는 움직임 없음 |
| 주차했을 때 | 주행 중 작은 창 화면의 `주차하면 넓어지는 모습 보기`로 확인 |
| 첫 실행 동의 | 차가 오른쪽에서 들어오고, 시간 순서 선이 왼쪽에서 오른쪽으로 그려지며 네 단계(통화 중, 통화 직후, 주차 후, 일해야 할 때) 카드가 차례로 올라옴. 카드 안에서 송풍 칸이 6단에서 2단으로 줄고 통화 띠가 자라남 |

## 가정한 것 (구현 쪽 확인 필요)

- 주행 중 작은 창의 크기: 앱 창의 1/3(561 × 1210)과 1/2(841 × 1210)로 가정.
- 비워 둔 왼쪽 위 구역: 480 × 200으로 가정.
- 상태 카드 크기: 기존 캡처와 같은 760 × 170.
- Gleo가 말하는 문장을 주행 중에 표시하는 것은 2026-11-15 사용자 요청으로 넣었습니다. 기획의 "주행 중 작은 창에는 아이콘 하나와 한 줄만" 규칙과 다르므로 기획 문서도 함께 고쳐야 합니다. 플랫폼의 주행 중 글자 수 제한에 걸리는지는 구현 쪽 확인이 필요합니다.
- 통화 종료 후 Gleo의 첫 물음은 2026-11-15 사용자 요청으로 "통화 요약을 듣고 싶으신가요?"로 정했습니다. 기획의 "통화가 종료되었습니다. 핵심을 요약해 드릴까요?"를 이 문장으로 바꿔야 합니다. 운전자가 "네"라고 답하면 요약을 들려줍니다.
- 앱을 소개하는 한 줄은 2026-11-15 사용자 결정으로 "당신을 위한 업무 비서"로 정했습니다(첫 실행 동의 화면에 표시. 처음에는 "차량을 위한 업무 비서"였다가 같은 날 바꿈). 기획 문서의 중심 문장 "통화에 맞춰 움직이는 차"는 이 문장으로 바꿔야 합니다.
- 대기 상태의 아이콘은 임시입니다. 앱 아이콘이 정해지면 바꿉니다.
- 통화 내용, 이름, 배터리와 출력 숫자는 예시입니다.

## 자료 출처

- 글꼴: 공모전 공식 글꼴 NeoHyundai (묶음의 `공식폰트`).
- 차량 그림: 묶음의 `참고\차량이미지` (`car_cabin.webp`, `05-cabin-cutaway.png`, `02-front-left.png`). 크게 당겨 보는 화면용으로 고해상도 그림에서 바탕을 오려 낸 `img\car_top_hd.webp`를 만들었습니다.
- 작업하는 사람과 노트북: 차량 그림 위에 흰 윤곽선으로만 직접 그린 그림(색 면 없음). 사람은 머리카락, 어깨, 소매, 손가락, 무릎까지, 노트북은 화면 내용, 카메라, 경첩, 자판, 스피커, 터치패드, 충전 단자까지 그렸습니다. 확대 그림은 미리보기 폴더의 `오피스_작업_사람과노트북_확대.png`입니다.
- 연락처 그림: 직접 그린 그림(김 팀장, 최 수석, 박 대리, 이 과장, 어머니). 사진을 등록하지 않은 연락처용 기본 사람 모양도 준비되어 있으나 지금 예시에서는 쓰지 않습니다.
- Gleo AI 아이콘: 사용자가 준 그림(https://image.edaily.co.kr/images/photo/files/NP/S/2026/10/PS26103000698.jpg, 520 × 520)에서 바탕을 오려 낸 `img\gleo.png`. 해상도가 낮은 기사용 그림이므로, 앱에 넣을 때는 공식 원본으로 바꿔야 합니다.
- 아이콘 일부: Feather Icons(MIT) 경로.

## 계획과 달라진 것

- Figma 셰이더는 이 연결에서 불러올 수 없었습니다(쓸 수 있는 셰이더 0개). 그라디언트, 배경 흐림, 입자감, 키프레임으로 대신했습니다.
- 옮긴 프레임은 자동 배치를 모두 풀고 위치를 고정했습니다. 글자를 도형으로 바꾸면 자동 배치가 무너지기 때문입니다.
- Figma AI 크레딧은 쓰지 않았습니다.

## 고친 문제 기록

- 2026-11-15: 움직임 프레임을 재생하지 않으면 겹쳐 보이던 문제, 사람 윤곽선 위치, 가리개 재질, 시트·운전대 오린 자국.
- 2026-11-15: 글자 도형이 Figma에서 늘어나거나 작아지거나 사라지던 문제. 원인은 세 가지였습니다.
  1. 글자 SVG를 1×1 상자에 넘치게 그리면 Figma가 일부를 늘림 → 상자를 실제 글자 범위에 맞춤.
  2. 가운데 정렬 상자 안에서 여백 보정이 Figma에서 무시됨 → 위치 기준 조상을 직접 찾아 left/top 지정.
  3. 지도 그림의 스타일(`.D-nav svg`)이 글자 SVG에도 적용됨 → 글자 SVG 크기를 우선 지정.
  크기 변환이 걸린 차량 그림 안은 1×1 방식이 맞게 옮겨져 그대로 둠.
- 2026-11-15 (4단계): 작업 ↔ 회의 장면에서 '작업' 단추에 회색 얼룩. 영상으로 그릴 때 배경 흐림이 아래 레이어의 움직임(투명도, 이동)을 무시하고 원래 모습을 비추기 때문이었음 → 레이어 순서를 바꿈.
- 2026-11-15 (4단계): 주차했을 때 장면에서 지도가 1px로 줄어듦. 원본 프레임이 가로 자동 배치였음 → 자동 배치를 풀고 위치 고정.
- 2026-11-15 (4단계): Gleo 대화에서 단계가 바뀔 때 앞뒤 말이 겹치거나 화면이 잠깐 빔 → 나가는 말 0.18초, 새 묶음은 0.08초 뒤 시작으로 조정.

## 움직임에서 알아 둘 제약

- 바람 줄기는 닫힌 도형이라 '선 그리기' 움직임이 안 됩니다. 가로 크기를 줄이고 왼쪽 끝을 맞추는 방식으로 했습니다.
- 글자가 도형이라 Figma 글자 움직임은 쓸 수 없습니다. 낱말이 밝아지는 움직임은 낱말 도형의 투명도로 했습니다.
- 움직임 프레임은 밤 화면만 만들었습니다. 낮 화면도 같은 시간과 곡선을 쓰면 됩니다.

- 2026-11-15 (5단계 검토 반영): 자주 누르는 동작(통화 바꾸기, 판 열기)의 차례 효과를 없애고 짧게 함. Gleo 대화의 탄성 곡선을 표준 곡선으로 바꿈. 해당 영상 4개를 다시 내보냄.

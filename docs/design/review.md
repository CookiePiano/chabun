# 차분 화면 검토 보고서

검토한 날: 2026-11-15 (KST)
방법: `better-interface` 스킬(접근성 → 배치 → 문구 → 글자 → 마감 순서), `full` 방식
Figma: https://www.figma.com/design/xWlfrz9eMEj20dAVqhuc9m (차분 화면 디자인)

결론: **고칠 것 있음.** 보고서만 만들었고, Figma 화면 옆에 검토 카드는 붙이지 않았습니다.

## 3. 검토했지만 고치지 않기로 한 것

| 위치 | 후보 | 고치지 않는 이유 |
| --- | --- | --- |
| 주행 중 작은 창 / Gleo 2~8 | 지시서·기획은 "아이콘 하나와 한 줄"인데 대화 문장이 여러 줄 보임 | 사용자가 2026-11-15에 대화 표시를 정했습니다. 대신 기획 문서의 해당 문장을 바꾸도록 명세 12장에 적었습니다 |
| 오피스 모드 화면 왼쪽 위 480 × 200 | 측방 카메라가 뜨는 비움 구역에 차량 그림 위쪽(앞유리 가리개)이 걸림 | 그 구역에는 그림만 있고, 가리개 상태는 오른쪽 목록 글자로도 보입니다. 글자와 단추는 구역 밖에 있습니다 |
| 낮 화면 강조색 글자 `#0A7D73` | 바탕 대비 4.28:1로 4.5:1에 못 미침 | 이 색을 쓰는 글자는 모두 24px 이상 굵은 글자(`내 약속`, 시간 순서 이름표 등)라 큰 글자 기준 3:1을 넘습니다 |
| 통화 띠의 보통 막대 | 막대 대비 밤 2.21:1, 낮 1.72:1 | 의미를 나르는 것은 못 들은 구간(주황 막대 + 이름표 글자)입니다. 보통 막대는 길이감을 주는 배경 무늬입니다 |
| 단추 "원래대로", "멈춤" | 동사로 시작하지 않음("원래대로 되돌리기", "멈추기") | 옆 판 폭(단추 하나 약 285px)에 32px 굵은 글자로 들어가지 않습니다. 화면 제목("원래대로 되돌리고 있습니다")이 뜻을 보충합니다 |

## 4. 확인한 것

| 확인 | 방법 | 결과 |
| --- | --- | --- |
| 색 대비 | `chabun.css` 37~38행의 낮·밤 색으로 WCAG 대비 계산(유리 카드는 바탕 위 합성색) | 18쌍 중 2번 항목만 기준 미달 |
| 터치 영역 | CSS 크기 확인 | 단추 높이 112, 통화 줄 104, 작업/회의 88, 판 닫기·더하기·빼기 84, 펼치기 76. 모두 76 이상 |
| 최소 글자 크기 | CSS 확인 | 24px 이상. 확대된 차량 그림 안의 17px 표시는 1.8배로 그려져 약 31px |
| 움직임 줄이기 | `chabun.css:370` | 웹 시안은 처리함. 앱에서도 같은 처리를 명세 8-4에 적음 |
| 움직임 영상 | 11장면을 30fps로 내보내 장면을 뽑아 봄 | 겹침·얼룩·빈 화면 없음 (고친 기록은 `읽어보기.md`) |

**확인하지 못한 것:** 실제 에뮬레이터 화면, TalkBack 읽기, 차량 조작기, 낮 화면 움직임(만들지 않음), 실제 햇빛 아래 낮 화면 대비.
